# NO IN THE PANTS · 급똥방지시스템

현재 위치 주변 화장실을 찾고, 화장실로 이동하는 동안 지압·자세·호흡·릴랙스 기능을 안내하는 모바일 우선 정적 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 간단한 정적 서버로 실행하면 됩니다.

## 네이버 지도 연결

1. 현재 앱에는 Maps JavaScript API Client ID `jfs5ldpnqa`가 기본 연결되어 있습니다.
2. 네이버 클라우드 플랫폼 콘솔에서 해당 Client ID의 웹 서비스 URL에 현재 실행 주소를 등록합니다.
3. 위치 권한을 허용하고 `내 위치로 화장실 찾기`를 누르면 실제 네이버 지도가 표시됩니다.

다른 Client ID로 테스트하려면 주소 뒤에 `?naverClientId=다른ClientID`를 붙이면 기본값보다 우선 적용됩니다.

키가 없는 상태에서도 위치 권한을 허용하면 OpenStreetMap 공개 데이터(Overpass API)에서 현재 위치 반경 1.5km의 실제 화장실을 검색해 목록으로 보여줍니다. 네이버 Client ID를 넣으면 같은 검색 결과가 네이버 지도 위에 마커로 표시됩니다.

초기 화면의 목록은 데모 데이터이며, 위치 검색 후 실제 데이터로 교체됩니다. 운영 단계에서는 호출량 제한과 데이터 이용 조건을 검토하고, 별도 백엔드 캐시 또는 공공 화장실 데이터 API 연결을 권장합니다.
